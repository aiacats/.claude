GUIアプリの実装完了時、UIテストを毎回必ず実行して正常性を確認すること。スクリーンショットの視覚確認まで含めて実装者（Claude）の責任。

**Why:** ユーザーからの指示。手動確認に頼らず、テストで動作保証した上で報告する。新機能を追加したらテストも必ず追加する。

**How to apply:**
- 一通りの実装が完了したら、コミット前にUIテスト（`dotnet run --project *.UITest`）を実行
- テスト結果がPASSであること、ログにエラーがないことを確認
- スクリーンショットを読み取って視覚的に変更が反映されていることを確認
- 問題があれば修正してから再テスト → PASSするまで繰り返す
- 正常性が確認できて初めてコミット・報告を行う
- テスト完了後、test-results/ 配下のスクリーンショットとscreenshot.pngは削除する
- **新機能を実装するたびに、その機能を検証するテストステップを必ず追加・調整する**
- テストは現状の全機能を網羅的にカバーすること
