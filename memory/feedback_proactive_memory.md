---
name: メモリの積極的構築（グローバル方針）
description: 全プロジェクトで会話中に得た情報を積極的にメモリへ保存する方針
type: feedback
---

会話中に得た重要な情報は、控えめにせず積極的にメモリへ保存する。

**Why:** ユーザーから「ある程度あなたの判断で構築していってほしい」「グローバルにも積極的に」と明示的に依頼された。

**How to apply:**
- グローバルメモリ: ユーザーの技術レベル、作業スタイル、全プロジェクト共通の好み・方針
- プロジェクトメモリ: そのプロジェクト固有の構成、採用技術の経緯、進行中の作業文脈
- 迷ったらプロジェクト側に保存する（スコープは狭い方が安全）
