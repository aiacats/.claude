---
name: メモリの積極的構築
description: 会話中に得た情報を積極的にメモリへ保存する方針
type: feedback
---

会話中に得た重要な情報は、控えめにせず積極的にメモリへ保存する。

**Why:** ユーザーから「ある程度あなたの判断で構築していってほしい」と明示的に依頼された。メモリが空に近い状態だと毎回ゼロから調査が必要になり非効率。

**How to apply:** 会話中に以下を検知したら即座に保存する:
- プロジェクトの目的・背景・採用技術の経緯
- ユーザーのフィードバック（肯定・否定どちらも）
- 外部リソースの場所や役割
- ユーザーの技術レベル・専門分野に関する情報
