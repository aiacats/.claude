- 中央: 3Dビューポート（Sceneビュー）

### 3Dビューポート内容
- 部屋空間（ワイヤーフレームのボックス + グリッド床）
- 複数のMoCapカメラ（カメラアイコン）が部屋の壁面/天井付近に配置
- 中央にヒューマノイド（被写体参照モデル）
- カメラからの視錐台が四角錐として描画（赤色・シアン色）
- 複数カメラの視錐台が交差する部分は色の変化で被覆率を表現

### アノテーション（画像内の説明文）
- 3DView上でカメラを選択でき、選択したカメラのGizmoが表示される
- 上下左右に移動・回転してカメラ位置を変更可能
- カメラからの四角錐が表示され、複数カメラで交差する
- 複数カメラに映る部分の色が変わるようにしたい（被覆率の可視化）
- 視点の角度を表すGizmo（右上）
