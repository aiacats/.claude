# 成果物を渡す

**報告は文章だけで終えない。** 見せられるもの（画面・動画・出来上がったファイル）を必ず添える
（グローバル CLAUDE.md「報告にはスクリーンショットを添える」）。

渡し方は 2 つ。使い分けはこれだけ。

| 渡し方 | いつ | 方法 |
|---|---|---|
| **そのまま送る** | 画像・小さいファイル・すぐ見てほしいもの | `SendUserFile`（別端末からも見られる） |
| **Drive へ置いてリンク** | 大きいもの（動画・ビルド）、他人へ転送するもの、あとから参照するもの | 下の `share.py` |

迷ったら両方でよい（画像は `SendUserFile` で見せ、動画はリンク）。

## Drive へ置く

```bash
SH=~/.claude/skills/deliver-artifact/scripts/share.py

python "$SH" put <ファイル> [名前]            # 上げてリンクを返す（本人 + 上記2アカウントのみ）
python "$SH" put <ファイル> [名前] --public   # リンクを知っている全員へ広げる
python "$SH" list                    # いま置いてあるもの
python "$SH" clean [日数]            # 指定日数より古いものを消す（既定 7 日）
```

置き場は共有用フォルダ（ID `1CFs1lfQmZAyQL_txLZ8u7r-FAkF2hyY9`）。
**ビルド成果物の自動配布先（`gdrive:Builds/<アプリ名>`）とは別**。あちらは SessionControl
デーモンが上げる場所なので、人の手で混ぜない。

**既定は「上げた本人 + komao9160@gmail.com + mao.komatsu@pjblue.com」だけが見られる**
（ユーザー指示 2026-09-23）。リンクを知っている全員へ広げたいときだけ `put <ファイル> --public` を付ける。
広げる前に一度確認する。**社外へ出せないものは上げない**。
迷うものはリンクにせず `SendUserFile` で直接渡す。

## 名前と掃除

- 名前には**日付を入れる**（`share.py put` が `-260923` を自動で付ける）。
  古いものを機械的に選べるようにするため。
- **拡張子を落とさない**。`put <ファイル> <名前>` の名前に拡張子が無ければ、
  元の拡張子と日付をスクリプトが補う（拡張子の無いファイルは、Drive から落としても
  種類が分からず開けない。2026-09-24 に実際にやった）。
- **セッションの終わり、または次に同じフォルダを使うときに掃除する**
  （`python "$SH" clean`）。確認のために上げたサンプル・中間生成物・古い版は残さない。
- 残すのはユーザーが「取っておいて」と言ったもの、まだ共有中のリンク。
- **まとめて消す前に `list` を見せる**。削除は戻せない。

## 渡す前に確かめる

- 画像・動画は**自分で開いて中身を見る**（動画は `video-analyzer` でフレームを抜く）。
  撮れているつもりで別のウィンドウが写っていた、という失敗を防ぐ。
- ファイルの中身が意図どおりか確かめる（動画なら `ffprobe` で解像度・尺・音声の有無）。
- 機密が写り込んでいないか見る（パスワード・鍵・他案件の画面・個人情報）。

## 素材の作り方

- 画面の静止画 … `windows-gui-testing` skill の `gui.ps1 shot`（PNG で保存できる）
- 画面の録画 … `screen-recording` skill（OBS → mp4）
- ビルド成果物 … 各プロジェクトのビルド手順。Tauri は `rules/app.md` 参照
  （リリース exe は SessionControl が自動で Drive へ上げるので、手で上げ直さない）
