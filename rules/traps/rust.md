# rust の罠

全件は ~/.claude/traps-catalog/rust.md。ここは再発しやすいものだけ。

### Mutex を保持したまま I/O しない
入力も新規作成も効かなくなる、別機器の操作で画面が固まる。原因はロックを持ったまま PTY 書き込み・機器 I/O・外部プロセスの起動待ちをすること。→ ロック内は `Arc` の取り出しだけ、I/O は解放後。（実例: 2026-06-11 Claudes / 2026-09-06 ftpDeck / 2026-09-13 ftpDeck）

### 受け手のいない channel
UI に何も届かない（エラーも出ない）。原因は `let (tx, _rx) = mpsc::channel()` で受信側を即 drop し、`try_send` が黙って捨てられること。→ 受信タスクを必ず spawn して消費する。（実例: 2026-02-20 natnet-recorder）

### チャネルの作り直しと一括ドレイン
合図が届かなくなる、開始直後のイベントを落とす。原因は待ち受けごとにチャネルを作り直して相手が古い口を持つこと、`while rx.try_recv().is_ok() {}` が直後の到着分まで捨てること。→ チャネルは所有者が 1 本持ち続け、捨てる分は到着時刻で選別する。（実例: 2026-08 Sequence）

### 子プロセスの stderr を読まずにパイプで溜めない
ffmpeg とアプリが互いに待って止まる。原因はパイプバッファの満杯。→ 別スレッドで読み切る。終了時は走っている子を覚えて `RunEvent::Exit` で止める。（実例: 2026-09-13 ftpDeck）

### 失敗を let _ / .ok() で握り潰さない
原因の分からない失敗・無制限ブロック・「ファイルが無い」表示に化ける。原因は ABOR やタイムアウト設定の失敗を捨てていたこと。→ Result を呼び出し元へ返す。（実例: 2026-09-03 ftpDeck）

### reqwest の .query() は空白を + にする
ブラウザでは通る API がツールからだけ失敗する。原因は form エンコードの `+` を空白へ戻さないサーバ（Titan）。→ `%20` で手組みし、サーバ側のログで届いた値を確かめる。（実例: 2026-06-06 AvolitesRemote）

### ログの置き場を cwd で解決しない
`cargo run` のログが target/debug/log に出る。原因は相対パスを作業ディレクトリ基準で解決すること。→ `package.json` / `Cargo.toml` を上方向に探したルートか exe の隣を明示する（Tauri は tauri の罠も参照）。（実例: 2026-03-08 Aether）
