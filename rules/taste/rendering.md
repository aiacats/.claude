# ユーザーの好み: 見た目・演出（シェーダー / ライティング / エフェクト / 演出）

シェーダー・ライト・エフェクト・演出のタイミングを作るときの美意識。過去に何度も直させた箇所から起こした。
全般の好みは `taste/general.md`。

- **影は純黒で、濃さはアルファだけで表す**。グレーにしない、ライトの色を被せない。
  （影の濃さ × ライトの色、のように色を混ぜる実装は一度はっきり断られている）
- **光の色が黒に近づくほど見えなくなるようにする**。色を黒にしたら「黒い光・黒いビーム」が残ってはいけない。
  RGB の明るさに応じてアルファも落とす。
- **エッジは柔らかく、ぼかしは綺麗に**。影のエッジは、物体に当たっている部分の柔らかさと揃える。
  正面から光を抜いたときに、硬いエッジのアルファが立たないようにする。衝突の境目がパキッと出たらぼかす。
- **色を転ばせない**。Bloom の光漏れは光の色だけを乗せ、薄い黒（くすみ）を入れない。書き出した画（EXR など）が暗くなっていないかを見比べる。
- 光の強弱の変化は、見た目で線形に感じられるようにする（数値の線形ではなく知覚の線形）。
- **軌跡は粒子の点々ではなく、太く繋がったリボン**で出す（Ribbon Trail）。
- ライブ演出の暗転は、曲の終わりに余裕を持たせる。
  既定: 終了 3 秒前から黒フェードを始め、0.5 秒前に暗転しきる。Timeline を止めるのは暗転しきってから。暗転明けは、暗転しきってから 1 秒待って始める。
  （案件ごとに変わりうる値。案件側に指定があればそちらに従う）
- 既存キャラ・マテリアル・Volume など、見え方が変わる値は、検証の間だけ変えて元に戻し、採否はユーザーに返す。採用された変更には戻し方を書く。
- 3D の機材・小物は、実物の写真どおりの形・向き・埋まり方・質感で作る。単色マットのモック調や、浮いて見える部品で出さない。
- リグと表情の制御は既製品（Auto-Rig Pro・Control Rig）に頼らず自作する。素材はクレジット表記の要らないもの（CC0 か自作）だけを使う。
- 3D は Unity へ持ち込む前提。作り始める前に用途（Unity へ持ち込む / Blender で完結 / 両方）を聞く（詳細は `blender-stage` skill）。
